Configuración inicial
Solo necesitas tu Client ID de OAuth 2.0. La app creará y configurará el Google Sheet automáticamente en tu Drive — sin pasos manuales.
Google Cloud Console → Credenciales → ID de cliente OAuth 2.0 (Aplicación web). Agrega http://localhost:8080 como origen autorizado.
Las 16 semanas del plan se mapearán a partir de esta fecha. Puedes cambiarlo después.
¿Qué hará la app automáticamente?
1. Busca en tu Drive un archivo llamado "Almacen Repuestos Tasks"
2. Si no existe, lo crea y configura con las 16 semanas del plan
3. Si ya existe (sesiones futuras), lo reutiliza directamente
