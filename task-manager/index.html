Configuración inicial
Conecta tu cuenta de Google para sincronizar tareas con Google Sheets.
Necesitas un Client ID de OAuth 2.0 (Google Cloud Console) y el ID de tu hoja de cálculo.
Google Cloud Console → Credenciales → ID de cliente OAuth 2.0 (tipo: Aplicación web). Agrega http://localhost y tu URL como orígenes autorizados.
Es la parte larga de la URL de tu Google Sheet: docs.google.com/spreadsheets/d/[ID]/edit
Las 16 semanas del plan se mapearán a partir de esta fecha.
Opcional pero recomendado. Google Cloud Console → Credenciales → Clave de API.
